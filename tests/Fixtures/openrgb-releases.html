OpenRGB Pipeline (Experimental)

SDK Version 6 | Plugin API Version 5


OpenRGB Pipeline builds are the latest unreleased development versions, automatically built from the latest changes from GitLab.

These builds often have better device compatibility, but may be unstable compared to the released versions.
